# Workflow

-------- Dynamic Workflow Types for Agentic Pipelines --------
A workflow is a sequence of steps that can include prompt calls, mapping, routing,
and parallel branches.

## Example Usage

```typescript
import { Workflow } from "rustyflows/sdk/models/shared";

let value: Workflow = {};
```
