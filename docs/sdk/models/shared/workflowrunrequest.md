# WorkflowRunRequest

Request body for workflow execution endpoints.

This mirrors the public, serialized subset of `WorkflowRunReq`. Runtime-only
fields such as tenant context, HTTP clients, and email services are injected
server-side and are intentionally absent from the API contract.

## Example Usage

```typescript
import { WorkflowRunRequest } from "rustyflows/sdk/models/shared";

let value: WorkflowRunRequest = {
  input: "<value>",
};
```
